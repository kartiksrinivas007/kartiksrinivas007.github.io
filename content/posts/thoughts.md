If powerful coding agents were to arrive, then what would we do as programmers?
By powerful I mean the type of programmers that can easily win an IOI gold.

As far as I see it, there are two outcomes.

1. Coding agents remain a leaky abstraction, and will never replace humans completely, there will still be a small amount of hallucination in the code they write, and this would require human intervention. In other words, the next token prediction only leads to distribution matching, and this "distribution matching" is not the definition of intelligence.

2. The agents become perfect and these models begin to have perfect multi-modal understanding. They understand nearly everything humans do from video and text inputs.



#### The First Case 

In the first case, it becomes imperative to know the *deeper* levels of the codebase. Knowing the inner details of the abstraction and being able to *debug* code become paramount. Efficient debugging of *failure*. *Evaluation* and low level heuristics that the model has not been trained on become *critical*. Simply knowing things or decisions that the model has not been trained on become important. *Experience* becomes important.

As more code is generated, it becomes imperative to make strong reliability benchmarks for the model (*Evaluation*) and worry about *regulations*

So I need to 

1. Amass as much experience as possible that the model has not been trained on
    1. Focus on *heuristics* that are used to improve performance that the model does not know
    2. Focus on *evaluation* and how to measure and suit models to needed behaviors

2. Become more productive in *using* the models themselves (Not that hard to do, since the software is always biased towards simplicity)

#### The second case

The second case simply teaches us that intelligence is prediction.

Perfect prediction machines are perfect intelligence machines.

This means we have a new super-species that is far more intelligent than you with text and video. It becomes hard to predict how the world would change (financial markets flooded with sophisticated algorithms, more ads, more fake news, political tensions rising)

The only missing piece is the physical one, the models, if physically intelligent can collect their own data and frame their own evaluations. The 2 most critical areas for which human intervention is needed. So the only way to make a useful career is to have large amounts of data and have the right eval metrics that you can set an "agent" on to build new models and new agents specific to your domain. But do we really need an agent to build another agent?

If continual learning is cracked, then the most *powerful* backbone (agent) becomes the most powerful agent. A single agent can *learn* and continuously beat new benchmarks that you make for intelligence based on the data you provide.
